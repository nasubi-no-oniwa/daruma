# 4つ目のダルマ

交互にダルマを落として4つ並べたら勝ち。3ターンごとに、小槌が指した段がだるま落としで抜ける。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目 |
| `js/config.js` | **調整はここ**（抜ける段の確率・何ターンごとか・持ち時間など） |
| `js/game.js` | ルール本体（落とす・4つ並び・だるま落とし・サドンデス） |
| `js/cpu.js` | CPU（よわい／ふつう／つよい） |
| `js/render.js` | ダルマ・盤・小槌の描画 |
| `js/online.js` | 合言葉オンライン対戦（部屋・手の送受信・観戦） |
| `js/firebase-config.js` | オンライン対戦の接続先（さかさまドロップと同じFirebase） |
| `js/main.js` | 画面の進行 |
| `database.rules.json` | Firebaseに貼る安全ルール（さかさまドロップと共通） |

## ルール

- 横7×縦6。赤と紺が交互に落とす。縦・横・ななめに4つ並べたら勝ち
- 2人が1回ずつ落として1ターン。3ターンごとに予告の段が抜ける（下から 35/25/18/12/7/3%）
- 抜けて2人とも並んだら、並んだ列が多いほうの勝ち。同数なら並んだダルマが消えて続行
